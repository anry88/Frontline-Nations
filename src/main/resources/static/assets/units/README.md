## Art Direction

The shared generation brief requested an original fictional class silhouette in a three-quarter top-down view, dark navy and gunmetal surfaces, restrained orange accent lights, a cool rim light, transparent background, generous padding, and readability at 64 px. It explicitly excluded real-world model identity, flags, insignia, text, logos, people, and watermarks. Each class prompt then specified only the equipment-defining silhouette and role.

Keep new icons within the same framing, palette, and neutral fictional treatment. Catalog entries reference these files through their public `/assets/units/...` paths.
